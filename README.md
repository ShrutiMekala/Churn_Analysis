# Customer Churn Analysis

### Data Analytics Project | Python | SQL | SQLite

## Project Overview
Analysed customer subscription, support and transaction data to identify churn patterns, customer retention trends and revenue impact for an OTT subscription platform.

## Tools & Technologies
- Python (Pandas, NumPy)
- SQLite
- SQL
- Matplotlib & Seaborn
- Jupyter Notebook

## Key Analysis
- Customer churn and retention rate.
- Churn by plan type and state.
- Average Revenue Per User (ARPU).
- Customer tenure and revenue at risk.
- Support escalations and their relationship with churn.
- Customer risk scoring and segmentation.

## Key Findings
- Overall churn rate: **28.6%**
- Monthly contract churn: **55.6%**
- Annual contract churn: **8.3%**
- Identified revenue leakage and customer lifetime value erosion.
